# Ponte E05/E09 de homologação — ainda não publicada

Este Worker prepara uma API de mesma origem **somente quando o painel e a API forem servidos pelo mesmo domínio**. A configuração de exemplo mantém `BRIDGE_ENABLED=0`. Não há domínio, banco, segredo ou implantação provisionados nesta entrega; a página atual ainda usa o transporte legado.

O primeiro recorte expõe `GET /api/v1/health`, `POST /api/v1/auth/login`, `POST /api/v1/auth/logout` e `GET /api/v1/projects/inventory?offset=0&limit=100`. Login troca credenciais no corpo por uma sessão opaca em cookie `HttpOnly`, `Secure`, `SameSite=Strict`; o token do Apps Script é cifrado em D1 e nunca volta ao navegador. Logout exige origem exata e `X-GESTCSI-CSRF`. O inventário requer a sessão, usa a action paginada `getClickUpInventory` e não converte falha da fonte em lista vazia. Nenhum comando de negócio ou proxy genérico está aberto.

`wrangler.example.jsonc` é apenas um modelo de homologação. O operador deverá criar uma configuração local ignorada, aplicar `migrations/0001_sessions.sql`, gerar `SESSION_ENCRYPTION_KEY` aleatória de 32 bytes em base64url, configurar `APPS_SCRIPT_URL` como URL HTTPS `script.google.com/macros/s/.../exec` e fazer smoke com usuários de cada papel. Nunca registrar os valores de secrets em Git. `npm run gateway:assets` copia apenas os três recursos estáticos usados pelo painel para `gateway/dist`; não converte automaticamente as chamadas JSONP da página.

Antes de ativar a ponte ou cortar o GET legado, faltam: testar Node/Workers em ambiente com runtime disponível; confirmar redirect do Apps Script e leitura paginada real; adaptar todas as ações sensíveis do navegador para a API da mesma origem; auditar papéis e dados por consultor; adicionar idempotência e trilha de auditoria aos comandos; testar revogação, CSRF, limite de tentativas e rollback no navegador. Para o histórico, conferir 337 projetos até 2025 e 215 em 2026 (552 no total) com sessão real. Uma leitura abaixo do piso de 201 ou timeout permanece indisponível, não zero. Esta ponte por si só **não restaura os projetos históricos em produção**.
